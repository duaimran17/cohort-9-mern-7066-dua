# cohort-9-mern-7066-dua
Cohort 9 — MERN (NodeJS+ReactJS) assignment for Dua Imran

SHINE Notes is a full-stack notes management platform built with the MERN stack (MongoDB, Express, React, Node.js). It provides real-time rich-text note creation, tag filtering, soft-delete trash auto-purging, import/export capabilities, and JWT authentication.
